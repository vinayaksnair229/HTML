tree data structure

Root:the root node is the topmost node in the tree hierarchy.in other words,the root node is the one that doesn't have any parent.in the above structure,node numbered 1 is the root node of the tree.if a node is directly linked to some other node,it would be called a parent-child relationship. child node:if the node is a descendand of any node,then the node is known as a child node.parent:if the node contains any sub node,then that node is said to be the parent of that sub-node.sibling:the nodes that have the same parent are known as siblings.
